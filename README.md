# AFi — Accounting of Finances

Мобильное приложение для учёта и анализа доходов и расходов малого 
бизнеса. Разработано как учебный проект в рамках курса «Визуальное 
программирование» с применением методологии работы с генеративными 
моделями («Золотые правила»).

**Платформа:** Android (приоритет), iOS и Windows — в перспективе  
**Стек:** .NET 10 + .NET MAUI + C# 12  
**Хранение:** SQLite, полностью локально  
**Автор:** Есипенко Игорь Ярославович

---

## О проекте

### Предыстория

У моего друга — небольшая кофейня. Он сам закупает зерно, платит 
за аренду, налоги и зарплату бариста, но постоянно путается в цифрах: 
сколько ушло на закупки в прошлом месяце, сколько стоила аренда, 
сколько нужно отложить на следующий месяц. Готовые решения (типа 
«Мой Склад», «Дримкас») либо слишком дорогие, либо перегружены 
функциями, которые микробизнесу не нужны.

### Цель

Простое приложение, которое:

- Позволяет за 5 секунд внести трату или доход.
- Показывает, куда уходят деньги, без сложных отчётов.
- Предупреждает о регулярных платежах и подсказывает ожидаемые 
  расходы на следующий месяц.

### Ключевые возможности

- **Учёт операций** — быстрый ввод доходов и расходов с категоризацией.
- **Позиции чека** — разбивка одной операции на конкретные товары 
  с ценой и количеством (например, «Молоко 3 шт × 90 ₽»).
- **Фото чека** — прикрепление фотографии к операции и полноэкранный 
  просмотр с пинч-зумом.
- **Визуализация** — круговая диаграмма расходов по категориям 
  и столбчатая динамика за 6 месяцев.
- **Drill-down** — топ позиций внутри каждой категории.
- **История** — детальный просмотр операций с фильтрами по периоду 
  и категории.
- **Напоминания** — уведомления о регулярных платежах за N дней 
  до даты.
- **Прогноз бюджета** — предсказание расходов на следующий месяц 
  гибридным алгоритмом.
- **5 тем оформления** — Светлая, Тёмная, Космос, Хеллоуин, Аркадная.
- **Мультивыбор** — массовое удаление операций и напоминаний.

## Требования

### Функциональные

#### 1. Ввод и категоризация операций

- Добавление дохода или расхода: сумма, категория, дата, комментарий.
- **Категории по умолчанию (расходы):** Аренда, Закупки (сырьё), 
  Налоги, Коммунальные услуги, АЗС, Транспорт, Кафе и рестораны, 
  Дом и ремонт, Одежда и обувь, Подписки, Цветы, Прочее.
- **Категории по умолчанию (доходы):** Выручка, Зарплата, 
  Прочие поступления.
- Каждая категория имеет **иконку-эмодзи** для визуального распознавания.
- Пользователь может **добавлять и удалять** свои категории 
  (стандартные — защищены от удаления).
- **Редактирование операций:** разрешено менять категорию, дату, 
  комментарий. **Сумма неизменяема** — принцип immutable amount 
  из бухгалтерского учёта.
- **Позиции чека** — разбивка операции на товары с количеством 
  и ценой. Если позиции есть, сумма операции = сумма позиций.
- **Фото чека** — прикрепление из галереи или через камеру.

#### 2. Визуализация статистики

- **Круговая диаграмма** — расходы по категориям за период.
- **Столбчатая диаграмма** — доходы и расходы за последние 6 месяцев.
- **Итоговые карточки** за период: Доход, Расход, Баланс.
- **Drill-down:** тап по «Топ позиций по расходам» внутри категории 
  показывает 5 самых крупных позиций.
- **Связка со страницей «История»:** тап по категории в легенде 
  открывает Историю с применённым фильтром по этой категории и периоду.

#### 3. Баланс и регулярные платежи

- **Баланс.** Пользователь вводит начальный баланс один раз. Приложение 
  показывает текущий: `начальный + доходы − расходы`.
- **Регулярные платежи** — напоминания, а не автоплатежи:
  - Название, сумма, день месяца.
  - Настройка «за сколько дней напоминать» (0–30).
  - Настройка времени напоминания.
  - Переключатель вкл/выкл для каждого платежа.
  - Локальные уведомления через `ExactAllowWhileIdle` (работает 
    даже в Doze-режиме).
- **Банковские карты не хранятся.** Приложение — учётный инструмент.

#### 4. Прогноз бюджета на следующий месяц

Гибридный алгоритм — **частотный фильтр + медиана**:

1. Берём 3 последних **полных** месяца.
2. Для каждой категории считаем, в скольких месяцах она встречалась.
3. **3 месяца** → медиана значений (устойчиво к выбросам).
   **2 месяца** → среднее.
   **1 месяц** → не включаем (разовые крупные траты).
4. Сумма «зачётных» категорий = прогноз.

**Пример:** если «Закупки» имели суммы 10 000, 12 000 и 80 000 ₽ 
(в одном месяце купили оборудование), среднее = 34 000 ₽ (завышено), 
медиана = 12 000 ₽ (реалистично).

### Нефункциональные

- **Локальное хранение** — все данные в SQLite, без сервера.
- **Работа офлайн** — приложение не требует интернета.
- **Кроссплатформенность** — Android, iOS, Windows из одного кода.
- **Простой UI** — минимум экранов, ≤2 нажатия до любой функции.

## Структура экранов

Приложение состоит из 7 основных экранов:

### Главная — рабочая панель

- Карточка текущего баланса.
- Форма ввода операции: сумма, тип, категория, дата, комментарий.
- Позиции чека (опционально).
- Фото чека (опционально).
- Список операций за последние 30 дней с группировкой по дням.
- Пагинация по 10 операций с кнопкой «Показать ещё».

### История — детальный просмотр

- Фильтр по периоду: 10 пресетов (Сегодня, Вчера, …, Свой период).
- Фильтр по категории.
- Итоговые карточки за период.
- Полный список с пагинацией по 100.

### Статистика — визуализация

- Переключатель «Круговая / Динамика».
- Круговая диаграмма расходов по категориям с легендой.
- Столбчатые диаграммы за 6 месяцев.
- Drill-down по категориям (топ-5 позиций).

### Напоминания — регулярные платежи

- Список напоминаний с переключателем вкл/выкл.
- Форма создания/редактирования: название, сумма, тип, категория, 
  день месяца, «за сколько дней», время, комментарий.

### Прогноз — предсказание расходов

- Расчёт по гибридному алгоритму.
- Таблица: категория → значение → включена в прогноз (да/нет).
- Итоговая сумма прогноза.

### Категории — управление

- Две вкладки: Расходы и Доходы.
- Список с иконками.
- Добавление и удаление пользовательских категорий.

### Настройки — выбор темы

- Сетка 2×3 с превью 5 тем.
- Мгновенное переключение без перезапуска.

## Этапы разработки

Проект разбит на **6 этапов**, каждый из которых начинался 
с планирования и заканчивался тестированием.

### Этап 1. Скелет приложения + ввод операций ✅

- Пустое MAUI-приложение на Android.
- SQLite с таблицами `Transaction`, `Category`.
- 15 категорий по умолчанию.
- Форма ввода и список последних операций.
- **Как проверить:** добавил расход → появился в списке → закрыл → 
  открыл → операция на месте.

### Этап 2. Управление операциями и категориями ✅

- Редактирование и удаление операций.
- Фильтрация по периоду.
- Экран управления категориями.
- Карточка баланса.
- **Как проверить:** отредактировал → баланс обновился; удалил 
  категорию с операциями → операции сохранились.

### Этап 3. Визуализация + тематизация ✅

- Круговая и столбчатая диаграммы.
- Связка Статистика → История.
- 5 тем оформления с мгновенной сменой.
- Кастомные `ThemedPicker`, `ThemedActionSheet`, `ThemedConfirm` — 
  в цветах темы.
- **Как проверить:** ввёл расходы в 3 категориях → диаграмма отражает 
  пропорции; сменил тему → всё приложение перекрасилось.

### Этап 4. Напоминания и уведомления ✅

- Экран «Напоминания» с настройками.
- Локальные уведомления через `ExactAllowWhileIdle`.
- Настройка «за сколько дней» и времени.
- **Как проверить:** добавил платёж на завтра → получил уведомление 
  в назначенное время.

### Этап 5. Прогноз бюджета ✅

- Гибридный алгоритм: частотный фильтр + медиана.
- Таблица прогноза в разрезе категорий.
- **Как проверить:** ввёл данные за 3 месяца, где «Аренда» есть 
  везде, а «Дом и ремонт» — один раз → в прогнозе есть «Аренда» 
  и нет «Дом и ремонт».

### Этап 6. Позиции чека, фото, drill-down ✅

- Модель `TransactionItem` и привязка к операциям.
- Позиции в форме с автоматическим пересчётом суммы.
- Прикрепление фото чека (галерея / камера).
- Полноэкранный просмотр с пинч-зумом (1–5x).
- Разворот карточки в списках.
- Drill-down топ-5 позиций в статистике.
- **Как проверить:** создал операцию с 2 позициями и фото → 
  карточка показывает «▸ 2 позиции · фото чека» → тап разворачивает 
  → тап по превью открывает фото на весь экран.

## Как запустить

### Требования

- **.NET 10 SDK** — [скачать](https://dotnet.microsoft.com/download/dotnet/10.0)
- **MAUI workload** — `dotnet workload install maui`
- **Android SDK** — устанавливается автоматически через workload
- **Физическое устройство** (Android) с включённой USB-отладкой 
  или эмулятор

### Сборка и запуск

```bash
# Клонировать репозиторий
git clone <url>
cd AFi

# Собрать для Android
dotnet build -f net10.0-android

# Запустить на подключённом устройстве
dotnet build -t:Run -f net10.0-android
```
